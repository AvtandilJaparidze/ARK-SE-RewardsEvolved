# RewardsEvolved

A rewards system for Ark: Survival Evolved.

Features:

* configurable random or guaranteed rewards
* console and RCON commands for giving rewards to players
* API for developers to use with other plugins

Console \& RCON Commands:

* RE.Reload (Reload the config)
* RE.Reward <steam\_id> <reward\_id\_from\_config> (Gives everything configured for a reward to the player)
